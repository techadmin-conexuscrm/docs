# One-click voicemail drop, voicemail consent per client and call centre, sticky DNC disposition, call card context, Preview push

**Base:** `claude/campaign-pr12-written-consents` · **Migration:** `0123` · **Merge order:** 13 of 14

## Problem
- Eric asked for a one-click "Machine: drop voicemail" for agents, on Auto dial and on manual dialer calls.
- It may only play when there is a consent basis for that number:
  - a written-consent record; or
  - the call centre's signed attestation for that client.
- A "Do not call" disposition must block the person, not only the number.
- Agents need their call card's campaign context.
- Free agents should be told when Preview cards are waiting.

## Root cause
None of this existed.

## Fix
- **Migration 0123** adds:
  - `voicemail_drops` (one per call, recording the placing company);
  - `voicemail_consent_mode_changes`, append-only: a trigger refuses UPDATE, DELETE and TRUNCATE;
  - `voicemail_drop_disposition_id` on the company settings.
- **BE-17 drop:**
  - the steps: check → Redis lock → FreeSWITCH `uuid_transfer` → save (3 retries, then a `result_not_saved` warning);
  - a drop FreeSWITCH accepted is never a 500;
  - signed links are redacted from ESL logs.
- **BE-18 consent mode:**
  - consent is set per (client company, placing call centre) pair;
  - it is signed by a native admin of the placing company, or a super admin, never by an API key;
  - the attestation text is versioned, and every change is logged with both companies;
  - routes: `PUT`/`GET /v1/dialer-campaigns/company-settings/voicemail-consent`, and `GET /v1/admin/organizations/:organizationId/voicemail-consent` (super admin).
- **D9 / X-24:**
  - the "Do not call" disposition blocks the customer wherever campaign dialing is on, and it is sticky;
  - only the agent on the call or an editor may pick it;
  - auto-dial never rings a customer once they are marked.
- **G-9:** `GET /v1/dialer/calls/:callId/campaign-context`.
- **G-10:**
  - My campaigns now reports `previewEnabled`, `previewCountdownSeconds` and `wrapUpSeconds`;
  - the pacer pushes `dialer:preview_offered` to free agents only.

## Why this is safe
- All routes are behind `CAMPAIGN_DIALER_ENABLED`.
- The drop needs a consent basis, a playable recording (audio, 30 s or less), and the agent on the call.
- **FreeSWITCH:** no FreeSWITCH or Kamailio configuration change is needed or made. The drop uses the existing ESL `uuid_transfer`. The read-only checks for Eric are in `docs/dialer/campaign-dialing/freeswitch-changes.md` (Part A).
- **DNC disposition:** this changes behaviour only for companies with campaign dialing on, which is none at deploy.
- The migration creates new tables and adds a column to a table created in this same deploy.
- Ships in **Deploy 2** (PR-02…PR-14 together, one restart). See the deploy plan.
